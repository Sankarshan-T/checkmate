# Checkmate
A really cool app built in react native to keep track of daily tasks to help life stay organized!!

## Features:
- Create tasks for each day
- Check off tasks
- Create global, reusable tasks
- Update tasks for each day in the calendar
- Get monthly reports on tasks (coming soon)

## How to install:
- Download the latest apk file
- Open it on your android device
- allow the installation prompts
- the app is installed on you device!!
